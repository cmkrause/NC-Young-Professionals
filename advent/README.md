# Seasonal reading plans

This preview is intentionally not linked from the sermon homepage. /advent/ is the landing page; ?plan=calendar or ?plan=road opens a plan; &day=YYYY-MM-DD deep-links to a day.

The renderer uses advent-2026.json (schemaVersion 1) for season metadata, theme start dates, resource symbols, individual ISO dates, titles, USFM scripture links and original source URLs. A video object has title, url, and optional verified youtube ID. Add another season by creating a new JSON file and configuring the entry point. The data uses original BibleProject links rather than copying devotional text or PDFs into this public repository, in line with its app sharing guidelines. Day 11's malformed Exodus 34:–6 reference is linked to Exodus 34:6, as cited in the corresponding reflection.

Completion key: gather-season:<season id>:<resource id>. Theme, font, size, and Bible translation use existing gather-* keys. The settings code in season.js is adapted from site.js; keep these in sync if settings change. Dates use device local time. No backend or accounts. For iframe playback verify individual video IDs; unsupported videos link to the official page.
